Mis 5 comandos favoritos de hoy

ComandoQué hace
docker run -d --name nombre imagenCrea y arranca un contenedor nuevo a partir de una imagen. Lo usé para levantar web1, web2, miweb y sitio.
docker ps / docker ps -aps muestra solo los contenedores corriendo; ps -a muestra todos, incluidos los detenidos. Me sirvió para confirmar que web1 seguía existiendo aunque estuviera detenido.
docker stop / docker startDetiene un contenedor sin borrarlo, y start lo revive después. Lo comprobé con web1.
docker exec -it nombre shMe abre una terminal dentro de un contenedor que ya corre, como entrar a otra computadora. Lo usé para ver los archivos dentro de miweb.
docker build -t nombre .Construye una imagen nueva a partir de mi propio Dockerfile. Así creé mi-sitio, mi primera imagen propia.
