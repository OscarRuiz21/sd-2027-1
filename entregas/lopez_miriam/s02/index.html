Los comandos de Docker que aprendí

Comando Para qué sirve
docker pull Me permite descargar una imagen de Docker para después utilizarla en mi computadora.
docker images Me muestra las imágenes de Docker que tengo almacenadas.
docker run Crea un contenedor y lo pone en funcionamiento utilizando una imagen.
docker ps Me permite revisar qué contenedores se están ejecutando actualmente.
docker build Construye una imagen nueva utilizando las instrucciones de un Dockerfile.
