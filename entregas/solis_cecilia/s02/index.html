Esta página la sirve un contenedor que yo construí.

Comando ¿Qué hace?
docker stop web1 Apaga el contenedor sin borrarlo; congela sus procesos y su estado temporalmente.
docker start web1 Vuelve a encender el contenedor detenido, conservando todo tal como quedó.
docker run -d -p 8080:80 --name miweb nginx:alpine Crea e inicia en segundo plano un contenedor con Nginx ligando el puerto 8080 local con el 80 interno.
docker exec -it miweb sh Abre una terminal interactiva dentro del contenedor en ejecución para inspeccionarlo internamente.
ls /usr/share/nginx/html Lista los archivos del directorio interno donde Nginx almacena y sirve el contenido web.
exit Cierra la sesión de la terminal interna del contenedor sin detener el servicio.
docker logs miweb Muestra el registro histórico de eventos, accesos y mensajes que el servicio ha emitido.
docker build -t mi-sitio . Compila una imagen propia llamada mi-sitio leyendo las instrucciones del Dockerfile en la carpeta actual.
docker images Muestra la lista de imágenes guardadas y disponibles en el almacenamiento local.
docker run -d -p 9090:80 --name sitio mi-sitio Arranca un contenedor en segundo plano con la imagen personalizada mapeando el puerto 9090.
