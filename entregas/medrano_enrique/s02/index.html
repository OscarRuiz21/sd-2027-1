Comando Descripción
docker exec -it nombre sh Nos permite acceder a la terminal dentro de un docker ya iniciado, de forma fácil.
docker pull imagen Permite descargar una imagen de Docker Hub (su tienda o biblioteca) sin necesidad de correrla.
docker tag viejo nuevo:tag Permite renombrar nuestra imagen.
docker ps -a Permite visualizar todos los dockers aunque estén detenidos.
docker stats Comprueba e indica los recursos consumidos por cada docker.
