Mis 5 comandos clave de Docker

Comando ¿Para qué sirve?
docker pull imagen Descarga la plantilla desde la tienda de Docker a mi computadora para tenerla lista, pero sin arrancarla.
docker run [opciones] imagen Crea un contenedor nuevo a partir de una imagen y lo enciende al mismo tiempo. Las opciones me dejan conectarle puertos o ponerle un nombre.
docker ps / -a Te muestra la lista de contenedores que están activos en este momento. Si le agregas el -a, te enseña absolutamente todos, incluyendo los apagados.
docker exec -it nombre sh Abre una terminal directa hacia las entrañas del contenedor. Es como meterte "dentro" de él para buscar archivos o ver por qué falló algo.
docker build -t nombre . Cocina mi propia imagen empacando los archivos actuales siguiendo las instrucciones del Dockerfile. El -t le pone el nombre o etiqueta.
