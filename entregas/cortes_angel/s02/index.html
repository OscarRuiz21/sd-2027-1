Esta página la sirve un contenedor que yo construí.

Comando Para qué me sirvió
docker run Crea un contenedor nuevo a partir de una plantilla y lo pone a funcionar inmediatamente.
docker ps Es como un administrador de tareas, me muestra la lista de los contenedores que están encendidos en este momento.
docker stop Apaga el contenedor de forma segura para que no consuma memoria, pero sin borrarlo.
docker exec Me permite meterme directamente al interior del contenedor para ver o explorar sus archivos.
docker build Empaqueta mis propios archivos (como esta misma página web) para crear mi propia imagen personalizada.
