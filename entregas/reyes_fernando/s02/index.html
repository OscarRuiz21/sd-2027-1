Comandos de Docker que más me sirvieron

Comando ¿Para qué sirve?
docker pull Me permite descargar una imagen de Docker para poder utilizarla en mi computadora.
docker images Muestra las imágenes de Docker que tengo guardadas en mi computadora.
docker run Crea y pone en funcionamiento un contenedor utilizando una imagen.
docker ps Me permite ver cuáles contenedores se encuentran ejecutándose en ese momento.
docker logs Muestra los registros de un contenedor y ayuda a revisar lo que ha ocurrido mientras se ejecuta.
