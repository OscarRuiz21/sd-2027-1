Tabla con comandos aprendidos el día de hoy:

Comandos Descripción
docker images Muestra un listado completo de las imágenes de Docker que ya están almacenadas de forma local en tu computadora.
docker pull imagen Descarga una imagen directamente desde el repositorio de Docker Hub hacia tu equipo, pero sin ponerla en ejecución.
docker ps / docker ps -a Permite visualizar los contenedores que están funcionando actualmente. Si agregas la opción '-a', también verás el historial de los que están apagados o detenidos.
docker stop / docker start Detiene el funcionamiento de un contenedor activo sin eliminar su información, o vuelve a arrancar uno que se encontraba previamente pausado.
docker rm / docker rmi Borra de manera definitiva un contenedor de tu sistema. En el caso de 'rmi', se utiliza específicamente para eliminar imágenes de Docker.
