Comandos Importantes de Docker

                                                                                                                                                                                           
Comando¿Para qué sirve?
docker run -d -p host:cont imagenCrea y corre un contenedor en segundo plano mapeando puertos de red.
docker build -t nombre .Construye una imagen personalizada a partir de las instrucciones del Dockerfile.
docker exec -it nombre shAbre una terminal interactiva dentro de un contenedor activo para depuración.
docker ps / docker ps -aLista los contenedores en ejecución o el historial completo de todos los existentes.
docker logs nombreMuestra la salida estándar y registros internos generados por el servicio.
