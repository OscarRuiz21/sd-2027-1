5 comandos clave

Comando Descripción
docker run [opciones] imagen Crea e inicializa un contenedor a partir de una imagen ya sea que esta se encuentre localmente o deba ser descargada.
Entre las opciones principales se encuentran:
  • -d: Ejecuta el contenedor en segundo plano
  • -p: Asocia un puerto del contenedor a un puerto del host
  • --name: Asigna un nombre al contenedor
  • -it: Abre una terminal interactiva dentro del contenedor
  • -v: Monta un volumen en el contenedor
  • -e: Establece variables de entorno
  • --rm: Elimina el contenedor después de su ejecución
docker ps -a Muestra todos los contenedores, su fecha de creación, estado y otros detalles.
docker build -t nombre_imagen . Construye una imagen a partir de las instrucciones en un Dockerfile que se encuentra en el directorio actual
docker images Muestra todas las imágenes disponibles y el espacio que ocupan.
docker exec [opciones] nombre_contenedor comando Ejecuta un comando dentro de un contenedor en ejecución.
Una de las opciones más comunes es -it para abrir una terminal interactiva de tipo shell dentro del contenedor.
