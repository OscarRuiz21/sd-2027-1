Los 5 comandos que más me sirvieron

Comando ¿Qué hace?
docker run Lo utilicé para crear y poner a funcionar un contenedor a partir de una imagen.
docker ps Me permitió revisar cuáles de mis contenedores estaban funcionando.
docker stop Sirve para detener un contenedor sin eliminarlo.
docker exec -it nombre sh Me permitió entrar al interior de un contenedor que ya estaba funcionando.
docker build -t mi-sitio . Sirve para construir una imagen utilizando el Dockerfile de mi carpeta.
