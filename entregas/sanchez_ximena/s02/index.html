Comandos de Docker aprendidos en la sesión:

Comando ¿Qué hace? (Explicación)
docker pull Descarga una imagen pública desde Docker Hub hacia mi máquina local.
docker run Crea y pone a funcionar un contenedor nuevo basado en una imagen.
docker ps Lista todos los contenedores que están activos en este momento.
docker build Crea una nueva imagen personalizada leyendo las reglas del Dockerfile.
docker rm Borra un contenedor de la memoria cuando ya no lo necesito usar.
