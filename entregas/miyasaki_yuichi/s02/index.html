Esta página la sirve un contenedor que yo construí.

Algunos comandos que me sirvieron para esta práctica fueron:

  • docker build: Este construye una imagen a partir de un Dockerfile
  • docker run: Se puede decir que ejecuta un contenedor a partir de una imagen
  • docker ps: Aqui muestra los contenedores en ejecución
  • docker start: Este inicia un contenedor detenido
  • docker logs: Muestra los registros de un contenedor
