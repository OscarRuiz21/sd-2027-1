Esta página la sirve un contenedor que yo construí.

Estos fueron los 5 comandos que más me sirvieron en la práctica

Comando Uso
docker pull imagen:tag Descarga una imagen que ocupé para montar la página en localhost. Bajé nginx en versión alpine.
docker run -d -p puerto-de-mi-máquina:puerto-del-contenedor --name nombre imagen:tag Crea y ejecuta un contenedor en segundo plano con un puerto de mi máquina abierto y un puerto del contenedor abierto. El nombre es arbitrario y se basa en la imágen y versión especificada.
docker logs nombre Imprime en la terminal todo lo que ha sucedido desde la creación del contenedor. Ahí pude ver mi visita a la página que se levantó.
docker build -t nombre Se crea una imágen a partir de los archivos que se encuentran en el directorio donde se ejecuta el comando. En este caso utilizó el archivo Dockerfile para configurar la imágen y index.html como el archivo con el contenido de la página web.
docker rm nombre Elimina el contenedor del nombre especificado.
