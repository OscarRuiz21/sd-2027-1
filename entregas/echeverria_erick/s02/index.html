Comandos mas utiles de la sesion

Comando ¿Para qué me sirve?
docker run -d -p Enciende un contenedor en segundo plano conectando un puerto de mi equipo al del contenedor.
docker ps -a Muestra la lista de todos los contenedores creados en el sistema, ya esten activos o detenidos.
docker exec -it Abre una terminal adentro de un contenedor encendido para explorar sus archivos.
docker images Muestra todas las plantillas o imagenes que he descargado o ejecutado en mi sistema.
docker build -t Lee el Dockerfile y construye una imagen de Docker a partir de los archivos actuales del proyecto.
