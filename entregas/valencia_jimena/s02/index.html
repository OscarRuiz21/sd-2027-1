Comandos que más me sirvieron

Comando ¿Para qué sirve?
docker pull Pude descargar una imagen de Docker para poder trabajar con ella.
docker images Lista las imágenes disponibles, se complementa bien con docker ps para saber que amágenes estan activas.
docker build -t mi-sitio . Me permitio crear la imagen del contenedor partiendo de un Dockerfile.
docker run Pude crear y ejecutar mi contenedor.
docker ps Me permitió identificar que contendores estan funcionando.
