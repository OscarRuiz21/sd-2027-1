Mis 5 comandos más útiles de Docker

Comando ¿Qué hace?
docker pull nginx:alpine Este comando es básicamente el inicio de mi trabajo con los contenderes, es la imagen que me proporciona la plantilla común para los contenedores sobre la cual se trabaja. Se usa para tener lista la plantilla para cuando se desee utilizar sin necesidad aún de iniciar ningún contenedor.
docker run -d --name web1 nginx:alpine Esta instrucción se encarga de crear contenedores, -d indica que se comience a ejecutar en segundo plano para que nosotros tengamos libre la terminal, se le da el nombre con --name y nginx:alpine especifica que se emplee el programa nginx usando la distribución alpine, que es un sistema ultraligero de Linux.
docker run -it --rm alpine sh Este comando me fue de utilidad y me pareció muy importante porque es en esencia el que nos permite trabajar en este sistema aislado que creamos (el contenedor), al usarlo podemos meternos dentro de él y se nos habilita la terminal de este sistema. Desmenuzando, "-it" entiendo que indica que se inicie la terminal de forma interactiva, manteniendo de esta manera la conexión entre mi pantalla y el interior del contenedor. Por otro lado "--rm" es un recolector de basura que funciona automáticamente, lo usamos para que al salir no quede rastro de nuestra entrada. La sección"alpine" indica solo que usamos la imagen pura del sistema operativo y "sh" solo solicita iniciar el "Shell", la línea de comandos básica de Linux.
docker run -d -p 8080:80 --name miweb nginx:alpine "Crea un contenedor en segundo plano llamado 'miweb' y publica su puerto interno (80) hacia el puerto 8080 de mi máquina, permitiéndome ver el servidor web desde mi propio navegador
docker logs miweb Este comando me parece de suma importancia ya que permite dar un historial de lo sucedido en todo momento dentro del contenedor y de esta forma poder detectar el origen de cualquier posible error.
