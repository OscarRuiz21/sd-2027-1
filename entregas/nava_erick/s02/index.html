Tabla con comandos Docker

Comando Descripción
docker run -d -p 9090:80 --name sitio mi-sitio El comando docker run crea al un contenedor haciendo uso de mi imagen y nombrandola, -d hace la ejecución en segundo plano, -p y el puerto es el puerto en que se asignada y el aprametro --name esta diciendo el nombre con el que se guardara y a imagen con la versión a utilizar
docker ps Docker ps enlista los contenedores actualmente activos, con la bandera -a muesta los que no
Docker build -t Comando para crear la imagen apartir de un Dockerfile, permite guardar el tag
docker rm Elimina un contenedor, pero debe de estar detenido. Con -f se forza a borrarlo
docker exec Te permite ingresar dentro del docker. Con -it haces dos cosas. La -i sirve para habilitar la entrada standar para interactuar con la terminal y -t es para tener una terminal similar a shell
