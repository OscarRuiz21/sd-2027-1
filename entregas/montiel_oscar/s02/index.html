Esta página la sirve un contenedor que yo construí.

Comando ¿Para qué sirve?
docker ps Siempre es importante ver los contenedores vivos; sirve para saber si algo está funcionado o si las cosas van bien. Es un comando básico pero importante.
docker stop / start Para pausar y reanudar contenedores. Como el anterior, son comandos básicos pero con una utilidad inmensa.
docker run -it --rm alpine sh Para correr un contenedor y meternos directo en su terminal (y que se borre solo al salir).
docker run -d -p 8080:80... No conocía este comando; sirve para arrancar el contenedor dejándolo en segundo plano y para inicializar el server en el puerto seleccionado.
docker build -t mi-sitio . Para crear nuestras propias imágenes (o los sitios) a partir de los archivos de nuestra carpeta.
