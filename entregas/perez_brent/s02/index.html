Mis 5 comandos de Docker más útiles

Comando ¿Para qué sirve?
docker build Lee las instrucciones de un archivo de configuracion "Dockerfile" para construir una imagen.
docker run Es el que le da vida a la aplicación, toma la imagen que se creó con build y genera un contenedor en donde estará el nuevo sistema operativo.
docker ps Es una herramienta que monitorea los contenedores, imprime una tabla en la terminal con la lista de los que están activos.
docker stop Le pone freno a un contenedor que está corriendo, apagándolo de forma segura sin borrarlo.
docker rm Borra por completo un contenedor que ya está apagado para limpiar el espacio en mi sistema.
