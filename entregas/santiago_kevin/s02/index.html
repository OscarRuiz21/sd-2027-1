Los 5 comandos que más me sirvieron

Comando ¿Por qué me sirvio?
docker ps Pude revisar qué contenedores están funcionando en ese momento.
docker run Crea y ejecuta un contenedor a partir de una imagen.
docker exec -it Para entrar a un contenedor que ya está corriendo y usar su terminal.
docker logs Ver los mensajes y registros que ha generado un contenedor.
docker build -t Construye una imagen usando el Dockerfile permitiendo asignarle un nombre.
