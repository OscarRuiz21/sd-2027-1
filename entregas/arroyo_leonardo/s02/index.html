Esta página la sirve un contenedor que yo construí.

Comando Para qué sirve
docker pull Para bajar plantillas (imágenes) desde Docker Hub y tenerlas listas en tu máquina.
docker run Para crear y arrancar un contenedor a partir de una imagen que ya tengas.
docker ps Para ver la lista de los contenedores que están corriendo (o todos si le pones -a).
docker stop Para detener un contenedor que esté en marcha, sin borrarlo.
docker build Para construir tu propia imagen personalizada usando un Dockerfile y los archivos que indiques.
