Comandos Utiles

Comando Descripción
docker ps Da una lista de los contenedores en ejecución, la opción -a nos lista incluso los que han no están ejecutándose y no se han borrado.
docker build Permite crear una imagen, empaquetar, agrupar y distribuir código.
docker exec Permite ejecutar un comando en terminal dentro del contenedor en ejecución.
docker run Inicia un contenedor a partir de una imagen, se puede usar la opción -it para utilizar la terminal, o -d para que se pueda seguir usando la terminal del sistema.
docker stop Detiene la ejecución de un contenedor para que deje de consumir recursos, pero sin borrarlo del sistema (rm).
