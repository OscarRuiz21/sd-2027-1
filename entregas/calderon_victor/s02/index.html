Comando utilizado ¿Qué hace? (con mis palabras)
docker runSirve para poder ejecutar un docker, es por así decirlo, el comando más importante.
docker ps -aEste otro comando sirve para poder ver todos los docker, tanto los activos como inactivos.
docker pull imagenDe las imagenes disponibles en la tienda se elige la que deseemos y con pull la traemos a nuestro local.
docker rmAl momento de correr este comando, vamos a ver que un contenedor se elimina
docker buildCon este comando, que considero el segundo más importante, podemos crear nuestro propio contenedor o incluso modificar una existente con un Dockerfile.
