Comando Qué hace (con mis palabras)
docker run -d -p Crea y arranca un contenedor en segundo plano enlazando un puerto local con uno interno.
docker ps -a Muestra todos los contenedores en mi equipo, tanto activos como apagados.
docker exec -it [nombre] sh Abre una terminal dentro de un contenedor en ejecución para explorar su interior.
docker logs [nombre] Consulta el registro de actividad y peticiones HTTP recibidas por el servicio.
docker build -t [nombre] . Lee el Dockerfile y empaqueta la aplicación en una imagen nueva e inmutable.
