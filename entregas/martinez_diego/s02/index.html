Mis 5 comandos más útiles de Docker

Comando ¿Qué hace?
docker build Construye una imagen a partir del Dockerfile.
docker images Muestra las imágenes que tengo disponibles en Docker.
docker run Crea y pone a funcionar un contenedor usando una imagen.
docker ps Me enseña los contenedores que están ejecutándose.
docker exec Me permite ejecutar comandos dentro de un contenedor que ya está funcionando.
