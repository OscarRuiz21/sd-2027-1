Esta página la sirve un contenedor que yo construí.

Los 5 comandos que más me sirvieron fueron:

Comando ¿Qué hace?
docker ps Lo uso para ver qué contenedores tengo corriendo en ese momento, con su ID, nombre, estado y puertos. Si le agrego -a, también me muestra los que ya están detenidos.
docker run Lo uso para poner a funcionar una imagen y crear un contenedor a partir de ella, todo en un solo paso.
docker exec Me sirve para meterme a un contenedor que ya está corriendo y ejecutar algo dentro, sin necesidad de apagarlo. Así puedo revisar qué está pasando por dentro en tiempo real.
docker logs Me deja ver todo lo que el contenedor ha ido imprimiendo desde que arrancó. Lo uso cuando algo no funciona y necesito entender qué está haciendo la aplicación sin entrar al contenedor.
docker run -it Es una variante de docker run que uso cuando quiero entrar directo a una terminal interactiva dentro del contenedor apenas se crea, en lugar de que corra en segundo plano. La "i" mantiene la entrada abierta y la "t" me da una terminal donde puedo escribir.
