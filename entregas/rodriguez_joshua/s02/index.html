Esta página la sirve un contenedor que yo construí.

Comando Descripción
mkdir -p El comando mkdir permite realizar una nueva carpeta (o directorio) desde la terminal. Además al añadirle el comando -p tenemos una ruta de carpetas anidadas
docker ps Lista los contenedores que están corriendo en el momento
docker run -d --name Crea un contenedor a partir de una imagen y lo hace correr con nombre fijo y en segundo plano
docker rm Permite detener la ejecución de un contenedor
docker logs Permite revisar los registros de un contenedor y ver si alguien accede a él
