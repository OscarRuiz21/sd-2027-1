Línea agregada para comprobar que la imagen es inmutable.

Mis 5 comandos principales de hoy:

ComandoDescripción de la función
docker runCrea e inicia un nuevo contenedor a partir de una imagen específica.
docker psLista los contenedores que se encuentran en ejecución en el sistema.
docker stop / rmDetiene un contenedor en ejecución y posteriormente lo elimina del sistema.
docker exec -itAbre una sesión interactiva de terminal dentro de un contenedor en ejecución.
docker buildConstruye una nueva imagen a partir de las instrucciones definidas en el Dockerfile.
