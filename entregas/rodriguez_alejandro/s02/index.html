Esta página la sirve un contenedor que yo construí para el laboratorio de la S02, SITIO 2.

Los comandos que más me sirvieron para esta práctica fueron:

Comando ¿Para qué sirvió?
docker run Crea un contenedor nuevo a partir de una plantilla y lo pone a funcionar.
docker ps Muestra una lista de los contenedores que están activos y funcionando en este momento.
docker stop Apaga un contenedor que está corriendo, pero lo deja guardado, por lo que no lo borra.
docker rm Elimina por completo un contenedor de la computadora, pero primero se tiene que apagar con stop.
docker build Lee las instrucciones del Dockerfile y construye una plantilla propia personalizada.
