ComandoMi explicación
docker pullDescarga una imagen (plantilla) desde internet a mi computadora local.
docker runCrea y enciende un contenedor completamente nuevo a partir de una imagen.
docker psMe muestra la tabla de los contenedores que están ejecutándose en este momento.
docker buildCocina una imagen nueva empaquetando mis archivos según las reglas del Dockerfile.
docker rmElimina definitivamente un contenedor que ya estaba detenido.
