5 comandos de Docker que mas me sirvieron

Comando Que hace
docker pull imagen Sirve para descargar una imagen de Docker Hub y poder usarla en mi computadora.
docker system prune Sirve para limpiar recursos que ya no se estan usando y pregunta antes de hacerlo.
docker run [opciones] imagen Crea y arranca un contenedor a partir de una imagen y permite configurar distintas opciones al ejecutarlo.
docker ps Me permite ver los contenedores que estan funcionando en ese momento.
docker build -t nombre . Construye una imagen nueva usando las instrucciones del Dockerfile.
