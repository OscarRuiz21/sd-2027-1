# Entregas

Una carpeta por persona, con tu **primer apellido y tu primer nombre, en minúsculas y sin
acentos, unidos por un guion bajo**:

```
entregas/
└── ramirez_ana/
    ├── s02/
    └── s03/ … s12/
```

Cada sesión se entrega desde una rama `sNN-apellido` como **pull request** con la
plantilla llena y la aprobación de tu revisor. Cada quien toca solo la suya.
