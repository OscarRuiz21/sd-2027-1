GATEWAY · A MANO · SI HAY TIEMPO

Si lo escribiéramos nosotros: una tabla y un reenvío

TABLA = {

"/api/cuentas": "http://cuenta:8080",

"/api/transferencias": "http://transferencia:8080",

"/api/movimientos": "http://movimiento:8080",

}

def atender(peticion):

for prefijo, destino in TABLA.items():

if peticion.ruta.startswith(prefijo):

ruta = peticion.ruta.removeprefix("/api")

return reenviar(destino + ruta, peticion)

return 404 # sin ruta: no pasa

Con esto ya enruta. Lo que falta es lo difícil: tiempos de espera, reintentos, límites, HTTPS, registro de cada petición y correr varias copias.

Enrutar son doce líneas. Todo lo demás es la razón por la que no se escribe: se usa uno ya hecho
