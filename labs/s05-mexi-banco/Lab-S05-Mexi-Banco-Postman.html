⬇️ Descargar la colección de Postman

Antes de empezar

Necesitas Docker corriendo (docker compose version responde) y Postman de escritorio (postman.com/downloads). La versión web de Postman no alcanza tu localhost.

Paso 1 · Clona el repo

git clone --branch v05.1 https://github.com/OscarRuiz21/mexi-banco.git
cd mexi-banco

Paso 2 · Levántalo con Compose

docker compose up --build -d
docker compose ps

db y app deben decir healthy, no solo running. Si app no llega, revisa docker compose logs app.

Paso 3 · Prueba los endpoints

En Postman: Import y arrastra la colección que descargaste arriba. Manda las peticiones en orden con Send y revisa lo que responde cada una: abrir cuentas, transferir, mandar el mismo SPEI dos veces, el estado de cuenta, los avisos y los errores.

Paso 4 · Bájalo con y sin volumen

# apaga, vuelve a levantar y consulta tu cuenta en Postman
docker compose down
docker compose up -d

# ahora apaga borrando el volumen, levanta y consulta otra vez
docker compose down -v
docker compose up -d

Anota qué pasó con tus datos en cada caso, y por qué.

Paso 5 · Revisa el código

Abre el proyecto en tu editor, en src/main/java/mx/mexibanco. Cada módulo (cuenta, movimiento, transferencia, notificacion y spei) tiene sus cuatro capas: controlador, servicio, repositorio y entidad. Familiarízate con él: es el monolito que vamos a ir partiendo en las siguientes sesiones.

Paso 6 · Estudia el compose y el Dockerfile

Léelos línea por línea, como en clase: qué servicios levanta el compose, el healthcheck, la red y el volumen; y en el Dockerfile, sus dos etapas, la que compila y la que ejecuta.

Entrega · un reporte corto

Un reporte en PDF, hecho con el procesador de textos que quieras, con tus observaciones de cada paso y capturas de lo que hiciste. Va en tu carpeta entregas/apellido_nombre/s05/, con push a tu rama y sin pull request.

git checkout entregas_apellido_nombre
git pull origin main
mkdir -p entregas/apellido_nombre/s05
# ... copia aquí tu reporte, por ejemplo reporte-s05.pdf ...
git add entregas/apellido_nombre/s05
git commit -m "S05: Mexi Banco con Compose"
git push
